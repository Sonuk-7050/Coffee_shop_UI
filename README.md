# ☕ Coffee Shop Website

A modern and responsive **Coffee Shop Website** built using **HTML, CSS, and JavaScript**.
This project provides a clean coffee-themed user interface with a navigation bar, hero section, menu, testimonials slider, gallery, contact form, and footer.

## 📌 Project Overview

The Coffee Shop Website is a front-end web development project designed to create an attractive online presence for a coffee shop.

The website includes:

* 🏠 Home / Hero Section
* ℹ️ About Us
* ☕ Coffee Menu
* 💬 Customer Testimonials
* 🖼️ Image Gallery
* 📞 Contact Section
* 📱 Responsive Mobile Navigation
* 🔗 Social Media Links
* 📄 Privacy & Refund Policy Links

The navigation provides links to Home, About, Menu, Testimonials, Gallery, and Contact sections.

## ✨ Main Features

### 1. Hero Section

The homepage introduces the coffee shop with the heading **"Best Coffee"**, a short description, and **Order Now** and **Contact Us** buttons.

### 2. About Section

The About section contains an image, description, and social media icons for Facebook, Instagram, LinkedIn, and Twitter.

### 3. Coffee Menu

The menu contains different categories:

* Hot Beverages
* Cold Beverages
* Refreshment
* Special Combos
* Desserts
* Burger & French Fries

### 4. Testimonials

Customer testimonials are displayed using **Swiper.js**. The JavaScript enables looping, pagination, navigation buttons, and responsive slider behavior.

### 5. Gallery

The gallery displays six coffee-shop images with a hover zoom effect.

### 6. Contact Section

The contact section contains:

* Location
* Email
* Phone number
* Opening hours
* Website
* Contact form

### 7. Responsive Design

The CSS includes responsive layouts for tablets and mobile devices. The navigation changes into a mobile menu on smaller screens, and menu/gallery items adjust their layout based on screen width.

## 📦 External Libraries

This project uses:

* **Font Awesome 7** for icons
* **Swiper.js 12** for the testimonial slider

These libraries are loaded through CDN links in `index.html`.

## 📱 Responsive Breakpoints

The website includes responsive behavior for:

* Desktop
* Tablet — up to 1024px
* Mobile — up to 900px
* Small mobile — up to 640px

The mobile navigation is controlled through JavaScript by toggling the `show-mobile-menu` class.
